# VPN address list (fallback copy)

ipv4.txt and ipv6.txt are a snapshot (commit dd4f2cc, 2026-09-29) of the VPN list from
https://github.com/X4BNet/lists_vpn (output/vpn). The server downloads a fresh copy once a
day and only uses these files when the download fails.
